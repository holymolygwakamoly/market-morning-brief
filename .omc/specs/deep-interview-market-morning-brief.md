## Goal
평일마다 사용자의 PC가 꺼져 있어도 클라우드에서 자동 실행되어, 미국장 마감 뉴스·한국장 관련 뉴스·거시경제 이슈를 무료 공개 소스(더벨 포함)에서 수집하고, LLM으로 **섹터 중심**(현재 이슈 섹터 / 상승 섹터 / 하락 섹터 / 그 이유 / 주도 대표주, AI 섹터는 항상 포함)의 매매 참고용 해석을 만들어, **핵심 요약 → 상세 분석 → 참고 자료** 3부 구성의 한국어 보고서를 **08:30 KST 이전**에 URL을 아는 사람이면 볼 수 있는 웹 페이지로 게시한다.

## Constraints
- **실행 시각**: 평일(월~금, KST 기준) 07:30 KST 시작, 08:30 KST 이전 게시 완료. 사용자는 08:40에 출근해 PC를 켜므로 그 시점에는 반드시 준비되어 있어야 함.
- **실행 환경**: 사용자 PC에 의존하지 않음. 무료 클라우드 러너(1순위 후보: GitHub Actions 무료 티어). 사용자 PC를 켰을 때 즉시 실행하는 로컬 트리거는 백업 경로로만 고려.
- **비용**: 유료 뉴스 API·유료 호스팅 금지. 발생 비용은 LLM API 호출뿐이며 월 1~2만 원 수준 목표.
- **뉴스 소스**: 무료 공개 소스만(RSS, 공식 발표 사이트, 무료 티어 금융 API, 공개 웹페이지 크롤링). 접근 가능한 소스는 최대한 폭넓게. robots.txt 및 사이트 이용약관 준수(유료 벽 우회 금지).
- **더벨(thebell.co.kr)**: 매 실행마다 반드시 확인. 단, 더벨 robots.txt가 검색봇 외 전면 `Disallow: /`이므로 **직접 크롤링 금지**. 대신 Google News RSS(`https://news.google.com/rss/search?q=site:thebell.co.kr&hl=ko&gl=KR&ceid=KR:ko`)로 **제목·링크·발행시각(헤드라인 수준)** 만 수집(2026-09-14 사용자 결정). 본문은 수집하지 않으며, LLM이 제목 기준으로 중요도를 판단해 보고서 포함 여부 결정, 포함 시 제목+링크로 인용.
- **커버리지**: 한국 주식 + 미국 주식 둘 다. 미국 뉴스는 미국 투자자 관점과 한국장 영향 관점 모두.
- **분석 비중**: 섹터 설명 > 개별 종목. 모든 섹터를 다룰 필요 없음 — 이슈가 있는 섹터, 상승 중인 섹터, 하락 중인 섹터와 그 이유, 이를 주도하는 대표주 몇 개. **AI 관련 섹터는 매일 항상 포함.**
- **분량**: 상한 없음(길어도 무방). 너무 짧으면 안 됨.
- **공개 범위**: URL을 아는 사람은 누구나 열람 가능(인증 불필요). 추측 어려운 URL이면 충분.
- **언어**: 보고서는 한국어. (인터뷰 중 가정으로 제시, 이의 없음)
- **LLM**: Claude API 사용. (인터뷰 중 가정으로 제시, 이의 없음) 비용 제약상 Sonnet 급 모델을 기본으로 하고 필요 시 조정.
- **실패 동작**: 소스 일부 실패 시 수집된 것만으로 보고서 발행 + 상단에 누락 소스 배너. LLM 실패 시 재시도 후에도 실패하면 전일 보고서 유지 + 실패 표시.

## Technical Context
(greenfield — 디렉토리 비어 있음. 아래는 인터뷰 결과에서 도출된 기술 방향이며 계획 단계에서 검증 필요)

- **런타임/스케줄러 후보**: GitHub Actions `schedule` cron `30 22 * * 0-4` (UTC 22:30 일~목 = KST 월~금 07:30) + `workflow_dispatch`(수동 실행, AC-19). GitHub Actions cron은 수 분 지연될 수 있으므로 08:30 마감까지 여유 확보. 무료 티어 한도(프라이빗 리포 월 2,000분) 내 충분.
- **호스팅 후보**: GitHub Pages (공개, 무료). 리포 자체는 공개/비공개 중 선택 가능하나 Pages는 공개 URL. `index.html` = 최신, `reports/YYYY-MM-DD.html` = 아카이브.
- **언어/라이브러리 후보**: Python 3.12, `feedparser`(RSS), `httpx` + `beautifulsoup4`(크롤링), `anthropic` SDK, `jinja2`(HTML 템플릿). 시세/지수: `yfinance` 또는 stooq CSV(무료).
- **LLM**: Claude API. 비용 기준으로 Sonnet 계열 기본. 수집 기사 → 1차 선별/요약(저비용) → 섹터 해석/보고서 작성(1~2회 호출)로 단계화해 토큰 절약. API 키는 GitHub Secrets에 저장.
- **소스 후보 (계획 단계에서 접근성·robots.txt 검증 필요)**
  - 미국: CNBC RSS, MarketWatch RSS, Yahoo Finance RSS, Reuters(무료 RSS 범위), Federal Reserve 보도자료 RSS, BLS/BEA 발표 일정, 경제 캘린더(공개 페이지)
  - 한국: 연합뉴스 경제 RSS, 한국경제/매일경제 RSS, 네이버 금융 뉴스(공개 페이지), 한국은행/금융위원회/금융감독원 보도자료, KRX 시장 정보, **더벨(thebell.co.kr) 공개 영역 — 필수**
  - 거시: 위 공식 기관 + 주요 지표 발표 일정
- **실패 처리**: 소스별 타임아웃·예외 격리 → `run_status.json`(성공/실패 소스, 기사 수, 토큰 사용량) → 템플릿에서 배너 렌더링. LLM 실패 시 지수 백오프 재시도 후 전일 파일 유지 + 실패 마커.
- **백업 경로(선택)**: Windows 작업 스케줄러 "로그온 시" 트리거로 로컬 실행 — 클라우드 장애 시 대비, 이번 범위 필수 아님.
